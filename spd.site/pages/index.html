SPD Editor for Eclipse

SPD（構造化プログラム図）を Eclipse の中で描くためのプラグインです。

アップデートサイトの URL

https://kawaba.github.io/eclipse-spd-plugin/

インストール

  1. Eclipse のメニュー ヘルプ → 新規ソフトウェアのインストール を開く
  2. 追加… を押し、「ロケーション」に上の URL を貼り付けて 追加（名前は空でよい）
  3. 一覧の「SPD Tools」の下にある SPD Editor にチェックを入れて 次へ
  4. 使用条件（EPL-2.0）に同意して 完了
  5. 途中で確認の画面が出たら、下の「署名について」を読んで進める
  6. Eclipse の再起動を求められたら 今すぐ再起動
署名について：このプラグインには電子署名を付けていないため、 「署名されていないコンテンツ」などの確認画面が出ます。 とにかくインストール（または「信頼する」）を選んで進めてください。

使い方

  • メニュー SPD → SPD エディタを開く またはツールバーのボタンで SPD エディタの画面が開きます。 描いた内容は自動で保管され、保存… で .spd ファイルに保存できます
  • SPD → 新規 SPD ファイル... で .spd ファイルを作ると、エディタで開いて Ctrl+S で上書き保存できます
  • Export した SPD を Java のエディタなどに貼ると罫線がずれる場合は、 SPD → フォントのフォルダを開く の中の README.txt を見てください

更新

ヘルプ → 更新の確認 で新しい版が入ります。 うまくいかないときは、ヘルプ → Eclipse について → インストール詳細 で SPD Editor をアンインストールしてから、もう一度インストールしてください。

動作環境

  • Eclipse 2025-09 以降（授業では Eclipse 2026 で確認しています）
  • Java 17 以上
